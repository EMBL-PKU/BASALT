# VAMB 5 compatibility

Current VAMB instructions are maintained under [Extra binners](BASALT_Guide/docs/extra-binners.md#vamb).

Before using `-e v`, verify the VAMB executable independently and record its version, PyTorch build, accelerator stack, and input BAM provenance. BASALT can continue after an optional adapter fails, so a completed BASALT process does not prove that VAMB contributed candidates.
